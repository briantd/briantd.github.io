gmail-to-zotero-sync

A personal utility. Single user, not distributed.

Privacy policyTerms of service

What it does

gmail-to-zotero-sync is a small program that runs on its owner's own computer. It reads selected messages from the owner's Gmail account and saves their contents to the owner's own reference library, so that long articles received by email can be read and kept in one place.

Why it asks for Gmail access

The program uses the Gmail API so that it can read the messages the owner has marked for it and update the labels on those messages once they have been saved. It does not send email and does not touch messages the owner has not marked.

Who can use it

Only the owner. The OAuth client exists so that the owner's own copy of the program can sign in to the owner's own Gmail account. There is no hosted service, no sign-up, and no other users.

Questions go to the support address shown on the Google consent screen.
