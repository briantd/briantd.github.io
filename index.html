gmail-to-zotero-sync

A personal reading pipeline. Single user, not distributed.

Privacy policyTerms of service

What it does

gmail-to-zotero-sync is a small command-line tool that runs on its owner's own computer. Every half hour it looks in the owner's Gmail account for newsletter articles the owner has labeled for reading, renders each one to a PDF, files it in the owner's Zotero library, and writes a reading note into the owner's Obsidian vault. When the owner finishes reading an article in Zotero and tags it as done, the tool pulls the highlights back into the note and archives the PDF.

Why it asks for Gmail access

The tool uses the Gmail API with the gmail.modify scope so that it can read the labeled messages and move their labels once an article has been filed. It never sends email, never reads messages outside the labels and senders the owner configured, and never shares mailbox content with anyone.

Who can use it

Only the owner. The OAuth client exists so that the owner's own copy of the tool can sign in to the owner's own Gmail account. There is no hosted service, no sign-up, and no other users.

Questions go to the support address shown on the Google consent screen.
