Summary

gmail-to-zotero-sync is a personal program with a single user, who is also its developer. It runs only on that user's own computer and only against that user's own accounts. It does not collect, store, or share data about anyone else.

What Google user data it accesses

With the user's consent, the program reads the Gmail messages the user has marked for it and changes the labels on those messages to record that they have been saved. That is the only Gmail data it touches. It does not read contacts, calendar, Drive, or any other Google service.

How that data is used

  • The contents of a marked message are saved to the user's own reference library on the user's own computer and in the user's own account with that library's provider.
  • Article text may be sent to a third-party text-processing API to produce a short summary. Only the article text is sent, never mailbox metadata, addresses, or credentials.
  • Google OAuth tokens are stored in a file on the user's computer, readable only by that user, and are used solely to call the Gmail API.

What it does not do

  • It does not sell, rent, or share Gmail data with anyone.
  • It does not use Gmail data for advertising, profiling, or training models.
  • It does not store Gmail data on any server operated by the developer.
  • It does not transfer Gmail data to any human other than the user.

Retention and deletion

Saved messages stay in the user's own library until the user deletes them. The user can revoke the program's Gmail access at any time from the Google Account security settings, which immediately stops all access. Deleting the token file on the user's computer has the same effect.

Limited Use

The program's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy go to the support address shown on the Google consent screen.
