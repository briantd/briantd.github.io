Summary

gmail-to-zotero-sync is a personal tool with a single user, who is also its developer. It runs only on that user's own computer and only against that user's own accounts. It does not collect, store, or share data about anyone else.

What Google user data it accesses

With the user's consent, the tool reads messages in the user's Gmail account that carry labels or come from senders the user chose, and it changes the labels on those messages to record that an article has been handled. That is the only Gmail data it touches. It does not read contacts, calendar, Drive, or any other Google service.

How that data is used

  • The text of a labeled message is rendered to a PDF and saved to the user's own Zotero library and Obsidian vault.
  • The article text may be sent to a third-party language-model API to produce a short summary, topic labels, and a self-quiz, which are saved alongside the note. Only article text is sent, never mailbox metadata, addresses, or credentials.
  • Google OAuth tokens are stored in a file on the user's computer, readable only by that user, and are used solely to call the Gmail API.

What it does not do

  • It does not sell, rent, or share Gmail data with anyone.
  • It does not use Gmail data for advertising, profiling, or training models.
  • It does not store Gmail data on any server. Everything lives on the user's own machine and in the user's own Zotero and Obsidian accounts.
  • It does not transfer Gmail data to any human, other than the user.

Retention and deletion

Filed articles stay in the user's Zotero library and vault until the user deletes them. The user can revoke the tool's Gmail access at any time from the Google Account security settings, which immediately stops all access. Deleting the token file on the user's computer has the same effect.

Limited Use

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
